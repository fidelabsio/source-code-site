# 2. Prerequisites checklist
- [ ] Node version in range installed (`node -v`)
- [ ] The project zip file (shared separately)
- [ ] A hosted PostgreSQL connection string (`DATABASE_URL`) — ask for this if you don't have it yet; no local PostgreSQL install needed
- [ ] A Shopify Partner account and a development store
- [ ] Your Partner app's Client ID (from `shopify.app.toml` after linking, or the Partner Dashboard)
---
# 3. Get the project files
1. **Download the project zip file** (shared separately — ask if you don't have a link/location for it).
2. **Extract (unzip) it** to a folder you'll remember, e.g. `Documents/fide-request-quote-hide-price-source-code`.
	- **Windows**: right-click the `.zip` → Extract All...
	- **Mac**: double-click the `.zip` file
3. **Open a terminal in the extracted folder** — every command in the next steps is run from this project's root folder (the one containing `package.json`, `app/`, `extensions/`, etc.).
<callout icon="💡" color="blue_bg">
	Extract the folder fully before opening it — don't open files directly from inside the `.zip`. Some tools let you browse a zip without extracting, which causes confusing errors later.
</callout>
---
# 4. Install dependencies
```shell
npm install
```
This installs the root app's dependencies as well as the theme app extension under `extensions/quote-request/` (an npm workspace).
---
# 5. Connect the codebase to your Partner app
```shell
npm run config:link
```
Wraps `shopify app config link` — prompts you to log in to Shopify CLI and pick (or create) a Partner app. Writes that app's `client_id` into `shopify.app.toml`.
<callout icon="🚫" color="red_bg">
	Do not commit someone else's `client_id`. If you're setting up your own instance, either link your own Partner app or change the value yourself.
</callout>
---
# 6. Configure environment variables
Copy the example file and fill in your own values:
```shell
cp .env.example .env
```

# 7. Set up the database
<callout icon="📖" color="blue_bg">
	Don't have a `DATABASE_URL` yet? See the **Database Setup Guide (Prisma Postgres)** for how to create one — no local PostgreSQL install needed.
</callout>
```shell
npm run setup
```
Runs `prisma generate && prisma migrate deploy` — generates the Prisma client and applies every migration under `prisma/migrations/` to the database at `DATABASE_URL`. Re-run any time you pull new migrations.
---
# 8. Run the application
```shell
npm run dev
```
Starts the Shopify CLI dev tunnel and the Vite dev server together. Press `p` in the terminal to open the app URL and install it on your connected development store.
---
# 9. Verify the installation
- [ ] `npm run dev` starts without errors and prints a tunnel URL
- [ ] The app installs successfully on your dev store when prompted
- [ ] The embedded admin UI loads inside Shopify admin (no blank iframe / auth loop)
- [ ] The Dashboard page renders with no console errors
- [ ] Submitting a test quote request from the storefront extension creates a row visible in the Quotes list
- [ ] `npm run lint` and `npm run typecheck` both pass on the untouched checkout
---
# 10. Common installation errors
<callout icon="❌" color="red_bg">
	**`The table 'main.Session' does not exist in the current database.`** — The database hasn't been migrated yet. Run `npm run setup`.
</callout>
<callout icon="❌" color="red_bg">
	**`ENCRYPTION_KEY` missing or too short (production only)** — Generate a 32-byte hex key as shown in step 6 and set it in your environment.
</callout>
<callout icon="❌" color="red_bg">
	**`"nbf" claim timestamp check failed`** — The JWT token appears expired — almost always a clock-sync issue. Enable "Set time and date automatically" in your OS settings.
</callout>
<callout icon="❌" color="red_bg">
	**Embedded app redirects/breaks inside the Shopify admin iframe** — A code-level gotcha, not an install issue, but the most common one right after first install — see "Gotchas / Troubleshooting" in the root README.md.
</callout>
<callout icon="❌" color="red_bg">
	**`npm install` succeeds but `shopify app dev` can't find a Partner app** — You haven't run `npm run config:link` yet (step 5), or you're logged into the wrong Partner organization in Shopify CLI.
</callout>
