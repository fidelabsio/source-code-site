**FIDE Shopify Source Code Product**
Version 1.0.0 · First Commercial Release
# 1. Release Overview
We are pleased to announce the first commercial release, v1.0.0, of the FIDE Shopify Source Code Product.
This release delivers a production-ready, white-label Shopify application that enables merchants to replace product prices with quote requests, manage customer quotations, and customize the application under their own brand.
In addition to the complete source code, this release includes comprehensive documentation, deployment guides, licensing documentation, and technical resources to help customers successfully install, configure, customize, and deploy the application.

# 3. Key Features
## 3.1 White-Label Architecture
The application includes a complete white-label architecture that allows customers to customize the application without modifying the core business logic.
Supported configuration includes:
- Application branding
- Colour theme
- Labels
- Email templates
- Business information
- Configurable settings
## 3.2 Quote Management
This release includes a complete quote management workflow. Features include:
- Hide product price
- Request quote button
- Configurable quote request form
- Merchant quote management
- Customer quote submission
- Email notifications
- Quote workflow management
## 3.3 Shopify Integration
The application has been developed using Shopify's recommended application architecture. Included integrations:
- Shopify Admin
- Shopify App Authentication
- Theme App Extension
- App Proxy
- Shopify Polaris
- Shopify App Bridge
